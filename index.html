Kỹ năng & Chuyên môn

Các mảng kỹ thuật và công cụ mình làm việc thực tế.

An Toàn Thông Tin & Vận Hành SOC
  • Giám sát SIEM: Phân tích nhật ký sự kiện (log analysis), phân loại cảnh báo và tham gia ứng cứu sự cố an toàn thông tin.
  • Bảo mật Web & API: Rà soát lỗ hổng theo chuẩn OWASP Top 10, kiểm tra logic xác thực và an toàn dữ liệu đầu vào.
  • Mạng & Phân tích gói tin: Sử dụng Wireshark để phân tích luồng traffic mạng, Nmap kiểm tra cổng và trạng thái dịch vụ.
SIEM Monitoring Log Analysis OWASP Top 10 Wireshark Nmap Incident Response
Phát Triển Phần Mềm & Ứng Dụng
  • Python Automation: Xây dựng script tự động hoá xử lý dữ liệu, bot tiện ích (Telegram) và tool hỗ trợ nội bộ.
  • Backend & APIs: Thiết kế RESTful APIs với Node.js / Express; làm việc với cơ sở dữ liệu MySQL và MongoDB.
  • Frontend Web: HTML5, CSS3, JavaScript ES6+, tư duy giao diện gọn gàng, tương thích tốt trên nhiều thiết bị.
Python Node.js JavaScript MySQL MongoDB Git & GitHub
Hệ Thống & Hạ Tầng Mạng
  • Quản trị Linux: Vận hành máy chủ Linux (Ubuntu, Debian), phân quyền, quản lý tiến trình và viết Bash script.
  • Mạng máy tính: Hiểu biết về mô hình mạng, bộ giao thức TCP/IP, DNS, định tuyến và phân tích lưu lượng.
Linux (Ubuntu/Debian) Bash Scripting TCP/IP & DNS
Sản Xuất Nội Dung & Đa Phương Tiện
  • Dựng video & Hậu kỳ: Sử dụng Premiere Pro, CapCut PC để dựng các nội dung video ngắn.
  • Chia sẻ công nghệ: Biên tập và chia sẻ kiến thức bảo mật, kỹ thuật số dễ tiếp cận cho cộng đồng.
